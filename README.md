# NAVIX: Interactive Struct & Meshing Studio

Navix represents the integration of direct topological engineering designs over B-REP frameworks cleanly pipelined directly into robust FEM backends, specifically starting with OpenCASCADE to Gmsh bridging natively managed all locally and efficiently visually.

## Tech Stack
-   **C++17 / C++20** standard library and design architecture structures.
-   **CMake** natively cross-links to external targets efficiently.
-   **ImGui** + **OpenGL 3+** for strictly lightweight user UI.
-   **GLM** explicit double structures for absolute grid logic.
-   **Gmsh Backend SDK**: Pre-compiled runtime mapping B-REP graph structures to explicit FEA outputs.

*Current State*: Meshing Engine integrated, nodes extracting accurately mapping graphical bounds directly back over standard scene spaces. Simulation strategy next focus via standard Eigen pipelines.
